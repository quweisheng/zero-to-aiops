# 零基础实验开课准备

先把“在哪里输入、文件在哪里、结果说明什么”弄清楚，再开始任何技术栈实验。这一页供各篇按需引用，不要求先学完一门编程语言或搭建整套平台。

## 取得课程文件，找到仓库根目录

打开[本课程 GitHub 仓库](https://github.com/quweisheng/zero-to-aiops)，点绿色 **Code → Download ZIP** 下载，解压到自己有写入权限的新文件夹。这里的 Code 是下载入口，不要求安装名叫 Code 的编辑器。若已经有本仓库，不要再覆盖已有学习记录。

根目录指同时能看到 `package.json`、`docs`、`examples` 的那层文件夹，不是 `docs` 内部，也不是 ZIP 外壳目录。`examples` 保存课程小实验，`docs` 保存文章。不要双击脚本期待看到完整输出：窗口可能一闪而过，应该在终端运行。

Windows 可以在这个文件夹空白处右键，选择“在终端中打开”，再选择 PowerShell。终端是输入命令、查看输出的窗口；PowerShell 是解释这些命令的程序。输入 `Get-Location` 查看当前目录，输入 `Get-ChildItem` 查看这一层文件。如果根目录在别处，输入 `Set-Location '实际完整路径'`，把引号中的文字换成自己的路径，不保留“实际完整路径”这几个字。路径有空格时保留引号。

Linux 终端用 `pwd` 查看当前目录、`ls` 查看文件、`cd '实际完整路径'` 切换。文章标为 Bash 的块在 Linux Bash 或明确适用的环境运行，不直接贴到 PowerShell；标为 PowerShell 的块反之。`$`、`PS>` 常是提示符，不是需要输入的命令，本文命令块不要求复制提示符。

## 运行 Node.js 课堂

Node.js 是在浏览器之外运行 JavaScript 的程序，不是一个网站账号。仅运行 `examples/teacher-led-reliability-lab/*.mjs` 时不需要启动本网站、不需要执行 `npm install`，也不需要购买云服务。

如未安装，使用 [Node.js 官方下载入口](https://nodejs.org/en/download)选择适合自己操作系统的受支持 LTS 版本。LTS 指长期支持版本；具体安装包以官方页面为准。Windows 安装后重新打开终端，输入：

```powershell
node --version
node examples/teacher-led-reliability-lab/lab.mjs slo
```

第一条应输出 `v` 开头的版本号；第二条应输出 JSON，也就是带字段名的结构化文本，并包含 `WITHIN_BUDGET`。它只用合成计数练习可靠性判断，不访问生产系统。显示“无法识别 node”时，先确认安装完成并重新开终端；显示找不到 `lab.mjs` 时，先核对根目录及解压层级，不要通过管理员权限猜着修。

## 运行 Python 课堂

Python 是另一种程序语言及其运行工具。文章使用哪个入口，就核对哪个入口的版本。Windows 常见 `py` 与 `python` 都可能存在，也可能指向不同安装；不能看见其中一个版本就假定另一个相同。

使用 [Python 官方下载入口](https://www.python.org/downloads/)安装受支持的 Python 3，重新开终端，先执行 `python --version`。若文章指定 `python` 而它不存在，可按安装说明配置入口，或把该实验全部命令统一改成已经验证的 `py -3`；不要只改一半。需要第三方库时，在文章指定的虚拟环境中安装，虚拟环境是本实验独立的一套依赖目录，不是虚拟机。

## 容器、虚拟机和商业平台先停一下

Docker 是管理容器的工具，容器是共享宿主系统内核的隔离进程环境，不等于完整虚拟机。`docker --version` 仅说明客户端存在，不能证明后台引擎正在运行；`docker info` 才能进一步检查连接。镜像下载、端口占用、内存和磁盘均可能成为前置条件，按具体文章核对，不能因为本文的 Node 实验成功就假定容器环境也可用。

虚拟机、数据库、集群和厂商平台必须使用自己获准的隔离实验环境。实验里给出的演示地址、账号、密码不是生产建议。启动服务前核对暴露范围，涉及删除、网络中断、扩缩容和证书时先保存状态并确认回退方法。不清楚对象是否共享，就停止该动作并向实际负责人核实。

## 怎样记录，才不把预期当实测

每次保留日期、操作系统、运行时与产品版本、命令、真实输出、判断和清理结果。文章写“预期”是让你比较，不能原样当作自己的运行记录。正常退出也不一定业务成功：有些课堂脚本退出成功，表示正确识别了故障，结果字段仍会要求阻断。

你可以把合成数据、脱敏配置、计算过程和失败记录提交到自己的学习仓库，不提交密码、令牌、客户日志、内网完整拓扑或个人信息。实验失败时先保留证据，再核对目录、工具、输入和权限；不要跳到重装系统或清空数据。清理只处理本文实验自己创建且已确认的对象，已有数据和共享资源不属于默认清理范围。
